# Resume Match AI

Lovable Prompt — CVMatch AI

Build a premium, modern, fully responsive SaaS web application called CVMatch AI.

CVMatch AI is an AI-powered resume analysis and optimization platform designed to help job seekers improve their resumes, understand ATS compatibility, compare their resume against specific job descriptions, identify skill and keyword gaps, and generate an improved ATS-friendly resume.

The product must feel like a real professional career-tech SaaS startup, not a generic AI-generated landing page.

1. CORE PRODUCT CONCEPT

The core experience must be extremely simple:

Paste Resume → Choose Analysis → Optionally Paste Job Description → Analyze → Get Match Score → Get Recommendations → Generate Optimized Resume → Copy or Download

The platform must work completely without registration, login, or account creation.

The user must be able to use the entire core product anonymously.

Do NOT require:

The user should be able to immediately access the product and start analyzing a resume.
